# 🧮 Mini Calculator Quiz Game

A fast-paced, console-based math quiz game built with C++. Test your mental calculation skills in Addition, Subtraction, Multiplication, and Division!

## ✨ Features
- **Endless Rounds:** Choose how many questions you want to tackle per game.
- **Lifetime Score Tracking:** Your score persists across multiple game sessions.
- **Smart Division:** The division logic is algorithmically designed to ensure whole number results (no annoying fractions).
- **Fool-proof Input Validation:** The game handles bad inputs gracefully without crashing.
- **Clean Architecture:** Built using modular functions, Enums, and the DRY principle.

## 🛠️ Built With
- C++ (Standard Library)

## 🚀 How to Play
1. Compile the `main.cpp` file using any C++ compiler (e.g., `g++ main.cpp -o game`).
2. Run the executable.
3. Enter your name, choose the number of rounds, and start solving!
